# 英単語帳

スマホで使える、自分用の単語学習 PWA（開発中）。

## 教材データについて

このリポジトリには**教材データ（音声・単語リスト・訳など）は含まれていません**。
自分で用意した教材パックをアプリに取り込んで使います。形式は [docs/CONTENT_FORMAT.md](docs/CONTENT_FORMAT.md) を参照してください。

## 開発

必要なもの: Node.js 22.12 以上

```sh
npm install
npm run dev
```
