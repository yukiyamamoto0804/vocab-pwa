# 教材パック形式

アプリが取り込む教材パックの形式。暗記カードの仕様（`docs/specs/study-cards.md`）に必要なデータから決めている。
**このファイルには形式だけを書き、実際の教材の中身は書かない。** 例はすべて説明用に作ったもの。

## パックの構成

```
my-pack.zip
├── manifest.json   # パックの情報とユニットの一覧
├── items.json      # 単語の一覧
└── audio/          # 音声ファイル
    ├── word-0001.mp3
    └── ...
```

- ファイル形式は JSON（UTF-8）。
- 全体を 1 つのフォルダに入れて圧縮した zip（`my-pack/manifest.json` …）も取り込める。OS が自動で加えるファイル（`__MACOSX/`、`.DS_Store` など `.` で始まるもの）は無視する。
- 単語から参照されていない音声ファイルは保存しない。
- `manifest.json`・`items.json`・`audio/` 以外のファイル（ライセンス文の `LICENSE`、説明の `README.md` など）は、入っていても保存しない（ファイル数と合計サイズの上限の計算には含まれる）。
- 音声のファイル名は英数字と `-`・`_`・`.` にする。zip を作るツールによっては英数字以外のファイル名が正しく読めず、`items.json` の指定と一致しなくなるため。`audio/` の中にフォルダを作った場合は、`audio/` からの相対パス（例: `sub/word-0001.mp3`）で指定する。

## manifest.json

```json
{
  "formatVersion": 1,
  "id": "my-vocab-pack",
  "title": "自分用単語パック",
  "createdAt": "2026-11-20",
  "license": "CC BY-SA 4.0",
  "attribution": "単語リストの出典: ○○（CC BY-SA 4.0）",
  "units": [
    { "id": 1, "title": "日常生活" },
    { "id": 2, "title": "自然と環境" }
  ]
}
```

| フィールド | 必須 | 説明 |
|---|---|---|
| `formatVersion` | ○ | 形式のバージョン。現在は `1` |
| `id` | ○ | パックを識別する文字列。同じ `id` のパックを再度取り込んだら更新として扱う |
| `title` | ○ | パックの名前 |
| `createdAt` | | 作成日 |
| `license` | | 教材のライセンス（例: `CC BY-SA 4.0`）。アプリはパックの情報に表示する。この項目に対応する前のアプリで取り込んだパックは、取り込み直すと表示される |
| `attribution` | | 出典・帰属表示の文（改行で複数行にできる）。アプリはパックの情報に表示する。他の人のデータを使って作ったパックでは、ライセンスが求める表示をここに書く |
| `units` | | ユニットの一覧。`items.json` でユニットを指定する場合に書く |
| `units[].id` | ○ | ユニット番号（1 以上の整数）。並び順はこの番号の順 |
| `units[].title` | | ユニットの名前 |

## items.json

単語の配列。配列の順番が、パック内の単語の並び順になる。

```json
[
  {
    "id": "0001",
    "word": "light",
    "unit": 1,
    "audio": { "file": "word-0001.mp3", "start": 0.0, "end": 1.2 },
    "senses": [
      {
        "meanings": [
          { "pos": "名詞", "meaning": "光、明かり" },
          { "pos": "形容詞", "meaning": "明るい" }
        ],
        "example": "The room was full of light.",
        "exampleTarget": "light",
        "exampleTranslation": "部屋は光で満ちていた。",
        "exampleTranslationTarget": "光",
        "exampleAudio": { "file": "example-0001-1.mp3" }
      },
      {
        "meanings": [{ "pos": "形容詞", "meaning": "軽い" }],
        "example": "This bag is very light.",
        "exampleTranslation": "このかばんはとても軽い。"
      }
    ],
    "idioms": [{ "phrase": "in the light of", "meaning": "〜を考慮して" }]
  }
]
```

### 単語

| フィールド | 必須 | 説明 |
|---|---|---|
| `id` | ○ | 単語の ID（パック内で一意の文字列）。学習記録はこの ID で紐づくため、一度決めたら変えない |
| `word` | ○ | 見出し語 |
| `unit` | | 所属するユニット番号（`manifest.json` の `units[].id`） |
| `audio` | | 単語の音声（後述の「音声の指定」） |
| `senses` | ○ | 用法の一覧（1 つ以上、3 つまでを推奨）。意味が大きく異なるものを分ける |
| `idioms` | | イディオムの一覧 |

### 用法（`senses[]`）

意味が大きく異なるもの（例: 「走る」と「経営する」）は別の用法にする。例文は用法ごとに 1 つ持つ。

- 用法は **3 つまでを推奨**する。学習画面では解説を必ずカード 1 枚に収めるため（スクロールしない）、用法が多いと文字が小さくなる。4 つ以上でも取り込みはできる。

| フィールド | 必須 | 説明 |
|---|---|---|
| `meanings` | ○ | 品詞と訳のリスト（1 つ以上）。ほぼ同じ意味で品詞が違うもの（例: 名詞「光」と形容詞「明るい」）は、1 つの用法にまとめる |
| `meanings[].pos` | ○ | 品詞（後述の一覧から選ぶ） |
| `meanings[].meaning` | ○ | 訳 |
| `example` | ○ | 例文（英語） |
| `exampleTarget` | | 例文の中に出てくる該当語の形（例: `runs`、`ran`）。穴埋めの空欄にする部分。省略時は見出し語を例文から探す |
| `exampleTranslation` | ○ | 例文の訳 |
| `exampleTranslationTarget` | | 例文の訳の中で、該当語にあたる部分（例: `光`）。日本語 → 解説の表面で太字にする。`exampleTranslation` にそのまま含まれる文字列にする。省略時や見つからないときは太字にしない |
| `exampleAudio` | | 例文の音声（後述の「音声の指定」） |

### イディオム（`idioms[]`）

イディオムは単語ごとに持つ（特定の用法には結びつけない）。

| フィールド | 必須 | 説明 |
|---|---|---|
| `phrase` | ○ | イディオム（英語） |
| `meaning` | ○ | 意味 |

### 品詞の一覧

`meanings[].pos` には次のいずれかを書く。自動詞と他動詞の両方の使い方がある動詞は、`meanings` に 2 つ並べる。

| 値 | 備考 |
|---|---|
| `名詞` | |
| `代名詞` | |
| `自動詞` | |
| `他動詞` | |
| `助動詞` | |
| `形容詞` | |
| `副詞` | |
| `前置詞` | |
| `接続詞` | |
| `間投詞` | |
| `句動詞` | |
| `その他` | 上のどれにも当てはまらないもの |

### 音声の指定

```json
{ "file": "word-0001.mp3", "start": 0.0, "end": 1.2 }
```

| フィールド | 必須 | 説明 |
|---|---|---|
| `file` | ○ | `audio/` 内のファイル名 |
| `start` / `end` | | 再生区間（秒）。1 ファイルに複数の音声が入っている場合に使う。省略時はファイル全体 |

## ユニット

- `items.json` で `unit` を指定する場合は、**全ての単語**に指定する（一部だけの指定はエラー）。指定した番号は `manifest.json` の `units` に存在しなければならない。
- `manifest.json` の `units` にあっても、単語が 1 つもないユニットは作らない。
- `unit` を指定しない場合は、`items.json` の並び順で 20 語ずつ自動で区切る（区切る語数はアプリの設定値）。最後のユニットは端数になる。自動で区切ったユニットには名前はなく、番号だけになる。

## 表面の種類ごとに必要なデータ

データが足りない単語は、その表面の種類では出題されない（`docs/specs/study-cards.md` 3 章・7 章）。出題しない単語があるときは、ユニット学習・復習ではアプリがその数を知らせる（詳しくは `docs/specs/study-cards.md` 3 章）。

| 表面 | 必須項目に加えて必要なもの |
|---|---|
| 英語 → 解説 | なし |
| 日本語 → 解説 | なし（`exampleTarget` がない場合は見出し語を例文から探し、見つからなければその用法は使わない。`exampleTranslationTarget` があれば訳のその部分を太字にする） |
| 単語の音声 → 解説 | `audio` |
| 例文の音声 → 解説 | `exampleAudio`（1 つ以上の用法に。音声がある用法だけを使う） |

## 取り込み時の検証

次の場合は取り込みを中止し、どの単語のどの項目が不正かを表示する。

- zip として開けない、`manifest.json`・`items.json` がない、または JSON として読めない
- 必須項目がない、または型が違う（任意の項目の `createdAt`・`license`・`attribution` も、書く場合は文字列にする）
- 文字列の項目（必須のものと、`exampleTarget`・`exampleTranslationTarget`・イディオム）が空、または空白だけ
- `id` がパック内で重複している
- `pos` が品詞の一覧にない
- `unit` が一部の単語にだけ指定されている、または `units` にない番号を指している
- `manifest.json` に `units` があるのに、どの単語にも `unit` が指定されていない
- `units[].id` が重複している
- パックや単語の `id` の前後に空白がある（見た目が同じ別の `id` になり、学習記録が引き継がれないため）
- `audio` / `exampleAudio` の `file` が `audio/` 内に存在しない、空（0 バイト。zip が壊れている可能性がある）、または 5 MB を超える
  - 区間を鳴らすときは音声ファイル全体を読み解くので、長いファイルはスマホのメモリが足りなくなる。大きさより長さが効くので、1 ファイルは数分以内を目安にする（ビットレートが低いと、5 MB 以下でも長くなりすぎることがある）
- `manifest.json`・`items.json` が UTF-8 として読めない（Shift_JIS などで保存したもの）
- `start` / `end` が負の数、または `start` ≥ `end`
- `items.json` が空
- zip のファイル数（OS が加えるファイルを除く）が 10,000 を超える、zip そのものや展開後の合計サイズが 200 MB を超える、または `manifest.json`・`items.json` が 1 つで 20 MB を超える（スマホのメモリ不足で止まるのを防ぐため）
- 1 段下のフォルダに `manifest.json` が複数ある（教材パックごとに別の zip にする）。zip の直下にある `manifest.json` は、下のフォルダのものより優先して使う。2 段以上深いフォルダの `manifest.json` は見つけない

## 取り込み直し

- 同じ `id` のパックを取り込むと、教材（ユニット・単語・音声）を全て新しい内容に入れ替える。確認は出さない。
- 入れ替えた後に、前の版との違い（追加・削除・内容の変更・変更なしの語数）を表示する。単語の `id` を誤って振り直したときに気づけるようにするため。

## 学習記録（参考）

学習記録は教材パックとは別に端末内に保存し、単語の `id` で参照する。教材パックを取り込み直しても、`id` が同じなら学習記録は引き継がれる。
