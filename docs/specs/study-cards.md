# 仕様書: 暗記カード

単語ごとの解説データから、表面の異なる複数の暗記カードを作り、裏返して確認しながら学習する仕組み。
項目ごとに検討し、決まったものから「決定事項」に書く。

| 状態 | 意味 |
|---|---|
| 未着手 | まだ検討していない |
| 検討中 | 論点を洗い出し中 |
| 決定 | 決定事項に従って実装してよい |

## 項目一覧

| # | 項目 | 状態 |
|---|---|---|
| 1 | 学習の基本方針（暗記とクイズの分離） | 決定 |
| 2 | 裏面（解説）の内容 | 決定 |
| 3 | 表面の種類 | 決定（細部は実装時に決める） |
| 4 | 多義語の扱い | 決定 |
| 5 | 判定（自己評価） | 基本方針は決定 |
| 6 | ユニットと出題の選び方 | 決定（設定値は使いながら調整） |
| 7 | 学習の流れ（表面の種類の選び方） | 決定 |
| 8 | 範囲・順番・量 | 6 章に統合 |
| 9 | 音声の再生設定 | 決定 |
| 10 | 解説の誤りの報告 | 決定（細部は実装時に決める） |

---

## 1. 学習の基本方針

### 決定事項

- 学習は**暗記カード**で行う。表面を見て頭の中で答えを思い出し、裏返して確認する。
- 正誤を自動判定する**クイズ**（綴りの入力、例文の穴埋め、選択式など）は、暗記とは別の機能として扱い、**当面は作らない**。
  - 理由: クイズは 1 問あたりの時間がかかる。裏返す前に思い出すこと自体が想起練習になり、暗記の効率を優先する。

## 2. 裏面（解説）の内容

### 決定事項

すべての表面の種類で、裏面は共通の解説を表示する。

| 項目 | 必須 | 備考 |
|---|---|---|
| 単語 | ○ | |
| 音声ボタン | ○ | 単語の音声を再生する |
| 品詞 | ○ | |
| 訳 | ○ | |
| 例文 | ○ | 基本は 1 単語につき 1 つ |
| 例文の訳 | ○ | |
| イディオム | | あれば表示する |

- 例文は基本 1 つ。意味が大きく異なる用法がある単語は、例文を複数持ってよい（4 章で扱いを決める）。

## 3. 表面の種類

### 決定事項

次の 4 種類の表面を用意する。

| 表面 | 表面に表示するもの | 主に鍛える力 | 必要なデータ |
|---|---|---|---|
| 英語 → 解説 | 単語 ＋ 単語の音声 | 英語を見て意味が分かる | 2 章の必須項目のみ |
| 日本語 → 解説 | 例文の訳 ＋ 該当語を空欄にした英語の例文 | 文脈の中で英単語を出せる | 2 章の必須項目 ＋ 例文中の該当語の位置 |
| 単語の音声 → 解説 | 単語の音声だけ（文字なし） | 音で聞いて意味が分かる | 2 章の必須項目 ＋ 単語の音声データ |
| 例文の音声 → 解説 | 例文の音声だけ（文字なし） | 文の中で単語を聞き取れる | 2 章の必須項目 ＋ 例文の音声データ |

- 必要なデータがない単語では、その表面のカードは作らない。

### 実装時に決める論点

各表面を実装するときに決め、ここに追記する。

- 例文中の該当語の位置を、どう特定するか（自動で文字列を探す / データで印を付ける）。活用形（例: 過去形・複数形）の場合の扱い。
- 単語・例文の音声がないとき、ブラウザ内蔵の音声合成で代用するか。
- 裏面に例文の音声ボタンも置くか。

## 4. 多義語の扱い

### 決定事項

- 意味が大きく異なる用法がある単語も、**カードは 1 枚にまとめる**。裏面に全ての用法を表示する。
- データは用法ごとに品詞・訳・例文・例文の訳を持てる構造にする（1 用法だけの単語は 1 つだけ持つ）。

### 実装時に決める論点

- 表面に例文を使う種類（日本語 → 解説、例文の音声 → 解説）で、複数の用法があるとき、どの用法の例文を出すか（毎回入れ替える / 最初の用法に固定する）。

## 5. 判定（自己評価）

### 決定事項

- 判定は自己申告とする。外部から定着を測る手段がないため、自己申告のブレは受け入れ、6 章の定着度でならして使う。

- 自己申告は **覚えた / 曖昧 / 忘れた の 3 段階**とする。

### 論点

- ボタンの配置（画面設計で決める）。

## 6. ユニットと出題の選び方

### 決定事項

- 単語は **約 20 語ずつのユニット**に分ける。ユニットを学習の区切りにする（必須）。
- 学習モードは次の 2 つを用意する。

| モード | 出題される単語 |
|---|---|
| ユニット学習（基本） | 選んだユニットの単語 ＋ **直前のユニットの学習済み単語（デフォルト 5 個）** |
| テスト（複数ユニットのランダム出題） | 選んだ複数のユニットの単語を混ぜて、ランダムな順番で出題する |

#### 役割分担

| 場面 | 担当 | 対象 |
|---|---|---|
| 普段の学習 | ユニット学習に混ぜる 5 個 | **直前 3 ユニット**の単語。学習して間もなく、最も忘れやすい時期をフォローする |
| 時々行う確認 | テスト | 広い範囲の古い単語。定着しているかを確かめる |

- 理由: 学習して間もない記憶ほど忘れやすく、復習を重ねた古い記憶は安定している。普段の学習は直近の復習に集中し、古い単語の確認はテストに任せる。
- 4 ユニット以上前の単語は普段の学習に出なくなるため、テストをしばらく行っていないときにテストを促す表示を用意する（例: ホーム画面に「最後のテストから◯日」「テストしていないユニット」を表示する）。表示の形は画面設計で決める。

#### ユニット学習に混ぜる 5 個の選び方

- 対象は直前 3 ユニットの学習済み単語。学習したユニットが 3 つ未満のときは、あるユニットから選ぶ。対象が 5 個未満なら、ある分だけ出す（0 個もありうる）。
- 当日すでに出題された単語は選ばない。
- 対象の中から、次の重みで**重み付きランダム**に選ぶ。定着度が低く、最後の出題から日数が経っている単語ほど出やすい。完全な優先順位にしないのは、同じ単語ばかり選ばれるのを防ぐため。

```
重み = (0.2 + (1 − 定着度)) × (1 + min(最終出題からの日数, 30) / 14)
```

- `0.2` は、定着度が満点の単語もたまに出るようにするための底上げ。
- 日数の項は 30 日で頭打ちにし、極端な値になるのを防ぐ。

#### 記録する値の単位

| 値 | 単位 | 使い道 |
|---|---|---|
| 定着度 | **単語ごとに 1 つ**（表面の種類によらず、全ての自己申告で更新する） | どの単語を出すか（重みの式） |
| 最終出題日 | **単語 × 表面の種類ごと** | 表面の種類ごとの学習状況の把握（7 章）。単語の重みの式には、いずれかの表面で最後に出題された日を使う |

- 単語ごとの定着度は分かりやすい一方、「英語を見れば分かるが、音声だと分からない」単語を数値で区別できない。生の記録から表面ごとの定着度を後で計算できる状態を保ち、使いながら必要になったら拡張する。

#### 定着度

単語ごとに、自己申告の結果を指数移動平均でならした値（0〜1）を持つ。

```
定着度 x_t = λ・y_t + (1 − λ)・x_{t−1}
```

| 記号 | 意味 | 初期案 |
|---|---|---|
| y_t | 今回の自己申告を数値にしたもの | 覚えた = 1 / 曖昧 = 0.5 / 忘れた = 0 |
| λ | 直近の結果をどれだけ重視するか | 0.4（1 回「忘れた」で定着度は 6 割に下がる） |
| x_0 | 初回の値 | 最初の自己申告の y |

- 定着度そのものは時間で減らない。時間の経過は、重みの式で最終出題からの日数として扱う。
- 回答ごとの生の記録（日時・表面の種類・自己申告）を全て残す。定着度は記録からいつでも計算し直せるため、λ や式を後から変えても過去のデータは無駄にならない。

#### ユニットの分け方

- 教材データ側でユニットを指定できるようにする。
- 指定がなければ、並び順で約 20 語ずつ自動で区切る。

#### テストの並び順

- デフォルトは**苦手優先**（定着度の低い順。同じ程度の単語どうしはランダム）。
- 完全なランダムも選べる。

#### 設定値

次の値は研究上の根拠がない出発点。コード内の設定値としてまとめて持ち、イメージと違ったら使いながら修正する。

| 設定値 | 初期値 |
|---|---|
| ユニットの単語数 | 約 20 |
| ユニット学習に混ぜる単語の数 | 5 |
| 混ぜる単語の対象範囲 | 直前 3 ユニット |
| 重みの底上げ | 0.2 |
| 日数の頭打ち / 日数の割る数 | 30 日 / 14 |
| λ | 0.4 |

### 論点

- 上の設定値のうち、どれを画面から変更できるようにするか。
- 間隔が空いた後の正解ほど定着度を大きく上げるか（研究上は、間隔を空けて思い出せたほうが強い定着の証拠）。当面は行わず、使いながら検討する。

## 7. 学習の流れ

### 決定事項

- 学習を始めるときに、**表面の種類を 1 つだけ**選ぶ。その回の学習は、全てのカードをその表面で出題する。
- 表面の種類の順番（例: 英語 → 日本語 → 音声）をアプリ側で強制しない。研究上のおすすめの順番は、選ぶ画面に参考として表示する程度にとどめる。
- 選んだ表面に必要なデータがない単語は、その回の出題から外す（ユニット学習に混ぜる 5 個の候補からも外す）。
- 最初に選ばれている表面の種類は、前回選んだもの。初回は「英語 → 解説」。

### 論点

- 選ぶ画面に、表面の種類ごとの最終学習日を表示するか（楽な種類ばかり選ぶ偏りに、自分で気づけるようにするため）。画面設計で決める。

## 9. 音声の再生設定

### 決定事項

- **自動再生はしない**。音声は再生ボタンを押したときだけ流す。音声だけの表面（単語の音声 → 解説、例文の音声 → 解説）でも、表面の再生ボタンを押して聞く。
- 繰り返して聞きたいときは、再生ボタンをもう一度押す。
- 再生速度は等速のみ。速度を変える機能は当面作らない。

### 将来の検討

- 例文の音声だけ再生速度を変えられるようにする。

## 10. 解説の誤りの報告

### 決定事項

- 裏面に「**この解説はおかしい**」と印を付けるボタンを置く。教材データの誤り（訳・品詞・例文・例文の訳・音声の区間など）に学習中に気づいたとき、その場で印を付けられるようにする。
  - 理由: 教材データは学習者が全てを事前に確認できるとは限らない。学習が進んで単語が分かってきた段階で気づいた誤りを、後でまとめて直せるようにする。
- 報告は学習記録の一つとして端末内に保存し、学習記録のエクスポートに含める。
- 報告の一覧を確認できるようにする（どの単語に印を付けたか）。

### 実装時に決める論点

- 報告にメモ（どこがおかしいか）を書けるようにするか。
- 教材パックを取り込み直して直した後、報告をどう扱うか（自動で消す / 手動で解決済みにする）。
- 報告の一覧をどの画面に置くか。
